# Автоматизированное тестирование

## Описание проекта

В проекте реализованы автоматизированные UI-тесты с использованием Selenium, pytest и Page Object.

Тесты проверяют:
- работу калькулятора;
- оформление покупки в интернет-магазине.

Для формирования отчётов используется Allure.

## Требования

Для работы проекта необходимы:

- Python;
- pytest;
- Selenium;
- allure-pytest;
- браузеры Google Chrome и Mozilla Firefox;
- Allure Commandline для просмотра отчёта.
